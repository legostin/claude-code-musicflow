# musicflow — дизайн

Мод для Claude Code: фоновая музыка с YouTube под вкус и настроение, рекомендации подбирает Claude.

## Цели

- Музыка с YouTube без браузера: `yt-dlp` ищет, `mpv` играет только звук.
- Рекомендации строит Claude (Haiku через `$.model.complete`) по описанию станции, настроению, лайкам/скипам и истории.
- Настроение: ручное (`/music mood спокойный фокус`) или `auto` — по сигналам сессии (ошибки Bash, частота правок, время суток).
- Станции (бесконечный поток по описанию) и плейлисты (фиксированные списки, «Liked» собирается сам).
- Интерфейс: компактная полоса над промптом (трек, прогресс, кнопки) + разворачиваемая боковая панель.
- Управление: `/music …`, кнопки, и инструмент `Music` для Claude в чате.

## Не цели (v1)

- Импорт аккаунта YouTube / cookies.
- Скачивание и офлайн-кэш.
- Визуализации, тексты песен.

## Архитектура

```
 session A ─┐                         ┌─ ~/.claude/musicflow/mpv.sock
 session B ─┼─ mod (hooks) ── nc -U ──┤   mpv --idle --no-video (detached, общий)
            │                         └─ ytdl_hook → yt-dlp → YouTube
            ├─ recommender (только лидер) ── $.model.complete(haiku) → запросы
            │                               └─ yt-dlp "ytsearchN:…" → кандидаты
            └─ $.store: вкус, станции, плейлисты, метаданные треков
```

### Модули

| Файл | Ответственность |
| --- | --- |
| `hooks/register.tsx` | события, команды, инструмент, отрисовка полосы и панели |
| `hooks/mpv.ts` | запуск демона `mpv`, JSON-IPC через `nc -U`, опрос состояния |
| `hooks/search.ts` | `yt-dlp` поиск, парсинг, фильтр кандидатов |
| `hooks/recommend.ts` | промпт для Haiku, парсинг ответа, fallback на YouTube-радио `RD<id>` |
| `hooks/taste.ts` | профиль вкуса: лайки, дизлайки, история, сигналы скипа/дослушивания |
| `hooks/mood.ts` | ручное/авто настроение, эвристика по сигналам сессии |
| `hooks/commands.ts` | разбор `/music` и входа инструмента в одно действие |

### Плеер

- Один `mpv` на машину: `--idle=yes --no-video --input-ipc-server=~/.claude/musicflow/mpv.sock --ytdl-format=bestaudio/best`, запускается через `sh -c 'nohup … &'`, поэтому переживает перезагрузку мода и закрытие сессии.
- Путь сокета короткий: на macOS лимит Unix-сокета 104 символа.
- Команда = один вызов `nc -U <sock>` с JSON-строками на stdin; `mpv` отвечает и закрывает соединение по EOF.
- Опрос раз в секунду: `media-title`, `time-pos`, `duration`, `pause`, `playlist-pos`, `playlist-count`, `path`, `volume`.

### Лидер

Несколько сессий делят один плеер. Рекомендации и запись истории делает только лидер: файл `~/.claude/musicflow/leader.json` `{ id, at }`; лидер — тот, чья запись свежее 20 с или кто первым её перехватил после устаревания.

### Рекомендации

1. Если в очереди после текущего < 3 треков и активна станция — генерация.
2. Haiku получает: станцию (описание), настроение, 15 последних лайков, 10 дизлайков, 30 последних сыгранных; отвечает JSON `{ "picks": [{ "query": "artist - track", "why": "…" }] }` (8 штук).
3. `yt-dlp --flat-playlist "ytsearch3:<query>"` → первый кандидат, прошедший фильтр: не играл за последние 200, не дизлайкнут, длительность 90–600 с (до 3600 с если станция `allowLong`).
4. `loadfile <url> append` (или `append-play` если плеер простаивает); метаданные `{ id, title, channel, duration, why, station }` в `$.store`.
5. Если модель недоступна / вернула мусор — YouTube-радио `RD<videoId>` от последнего лайка или текущего трека.

### Сигналы вкуса

- ♥ like: +, добавляет в плейлист «Liked».
- 👎 dislike: −, и сразу next.
- Смена трека при прогрессе < 25% — скип (слабый −), > 80% — дослушан (слабый +). Пишет только лидер.

### Настроение

- `manual`: текст пользователя как есть.
- `auto`: окно 15 мин по событиям `tool.call`: доля упавших Bash, число правок (Edit/Write), час суток → метка (`calm debugging`, `deep focus`, `upbeat flow`, `late night chill`, `morning warmup`). Пересчёт не чаще раза в 10 мин; смена метки не сбрасывает очередь, влияет на следующие генерации.

### Интерфейс

- Полоса над промптом (только когда что-то играет или грузится): `♪ Title — Channel  1:23/3:45 ▮▮▮▯▯  [⏯] [⏭] [♥] [👎] [≡]`.
- Панель `musicflow` (`/music panel` или `[≡]`): сейчас играет + прогресс, кнопки, настроение (select + поле), очередь (5 следующих с «почему»), станции (список + создание), плейлисты.
- Без автозапуска музыки при старте сессии.

### Управление

`/music` без аргументов — панель. Подкоманды: `play <запрос>`, `station <описание>`, `pause`, `resume`, `next`, `like`, `dislike`, `mood <текст|auto>`, `playlist save <имя>`, `playlist play <имя>`, `vol <0-100>`, `stop`, `now`.
Инструмент `mcp__musicflow__Music` с `action` и `value` — те же действия для Claude.

### Ошибки

- Нет `mpv`/`yt-dlp` — тост с `brew install mpv yt-dlp`.
- `yt-dlp` устарел (YouTube меняет API) — при ошибке воспроизведения тост «обнови yt-dlp: brew upgrade yt-dlp».
- Сокет мёртв — перезапуск `mpv` при следующей команде.
- Модель недоступна — fallback на радио.

### Тесты

`claude plugin test`: разбор команд, фильтр кандидатов, парсинг ответа модели, сигналы вкуса, эвристика настроения, отрисовка полосы и панели (с подменой `process.run` и `model.complete`).
